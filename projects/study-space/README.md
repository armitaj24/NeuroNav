# Study Space ✳

A gentle study planner concept for balancing coursework, graduate applications and life outside university.

Open [index.html](index.html) in a browser after downloading the repository. Add, edit, complete and delete tasks; navigate a weekly view; use the focus timer; and print the week as a paper planner. Three starter tasks are explicitly labelled as examples.

Tasks are saved in the browser on the current device; the focus timer lasts for the current session. Clearing browser data can remove saved tasks. This is an AI-assisted prototype, not a synced calendar or reminder service.
