How does a neuron pass a message?

Let’s start with one small building block. Neurons are cells that help the nervous system communicate. A neuron receives signals, processes them and can send a signal onward to another cell.

THE SHORT VERSION

Many neurons receive input through dendrites. An electrical signal can travel along the axon. At many synapses, the neuron releases chemicals called neurotransmitters that carry the message across the gap.

01 / RECEIVEDendrites

Branching structures receive signals from other cells.

02 / TRAVELAxon

An action potential can carry a signal away from the cell body.

03 / CONNECTSynapse

Signals can pass to another cell across this connection.

A question to take away

What changes at a synapse when we learn? That’s a great next question — and a reminder that understanding the brain is a journey, not a race.
